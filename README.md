# EECE 4081 Individual Application Project

## Student Task Tracker

### Concept Brief

The Student Task Tracker is a web application designed to help students organize their academic work in one place. A user will be able to create tasks for assignments, exams, projects, and other school responsibilities, assign a due date and priority to each task, and mark tasks as completed. The application will also allow the student to view pending and completed tasks so that it is easier to keep track of upcoming work. The goal of this project is to build a small but complete web application that can be developed and improved throughout the EECE 4081 Individual Application Project milestones.

### Declared Stack

- **Language:** Python 3.12
- **Web Framework:** Django
- **Database:** SQLite
- **Package Manager:** pip
- **Test Runner:** pytest with pytest-django
- **Version Control:** Git
- **Repository Hosting:** GitHub
- **Development Environment:** Visual Studio Code

### Current Milestone

IAP-M1 establishes the initial project repository and verifies that the development toolchain is working. The project currently contains the initial Django project structure and a basic automated test used to verify the testing environment.
